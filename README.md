# ETERNAL Ltd. Stock Analysis & Trading Strategy

## Overview

A Python-based stock analysis project using historical data for ETERNAL Ltd. The project analyzes price trends, returns, moving averages, volatility, drawdown, and moving-average-based trading signals.

## Key Analysis

- Daily Returns
- 20-day Moving Average (MA20)
- 50-day Moving Average (MA50)
- Annualized Volatility: **46%**
- Maximum Drawdown: **-69.8%**
- Buy Signals: **10**
- Sell Signals: **9**

## Tools

Python | Pandas | NumPy | Matplotlib | Jupyter Notebook | Excel
